============================================================
  АРЕС — ШПАРГАЛКА ДЛЯ ЗАПУСКА
  (Django 5.2 + React 18 + Vite)
============================================================

ЧТО НУЖНО УСТАНОВИТЬ
  Python 3.12+          https://www.python.org/downloads/
  Node.js 20.19+ / 22+  https://nodejs.org/
  Проверка версий:  python --version   &&   node -v

------------------------------------------------------------
ЗАПУСК — ДВА ТЕРМИНАЛА
------------------------------------------------------------

ШАГ 1. БЭКЕНД (первый терминал)

  cd backend
  python -m venv venv

  Активировать виртуальное окружение:
    Windows (cmd):      venv\Scripts\activate
    Windows (PowerShell): venv\Scripts\Activate.ps1
    Linux / macOS:      source venv/bin/activate

  pip install -r requirements.txt
  python manage.py migrate
  python manage.py create_admin
  python manage.py runserver

  -> Сервер работает на http://127.0.0.1:8000
     Это окно НЕ закрывать, пока играете.

ШАГ 2. ФРОНТЕНД (второй терминал)

  cd frontend
  npm install
  npm run dev

  -> Откроется http://localhost:5173

ШАГ 3. ОТКРЫТЬ В БРАУЗЕРЕ

  Сайт:            http://localhost:5173
  Админка Django:  http://localhost:5173/admin/
                   (или напрямую http://127.0.0.1:8000/admin/)

------------------------------------------------------------
ГЛАВНЫЙ АДМИНИСТРАТОР
------------------------------------------------------------
  Команда  create_admin  без аргументов создаёт:
    Логин:  exampleuser123
    Пароль: example444

  Свой логин/пароль сразу:
    python manage.py create_admin --username ares --password МойПароль123

  Выдать/снять права администратора сайта другому пользователю:
    python manage.py setadmin <ник> on
    python manage.py setadmin <ник> off

------------------------------------------------------------
ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
------------------------------------------------------------
  * Порт 8000 занят:
      python manage.py runserver 8001
      и поменять порт в frontend/vite.config.js (target: ...8001)

  * «Нет связи с сервером» на сайте:
      бэкенд не запущен — проверьте первое окно (runserver).

  * Ошибка про corsheaders / модуль не найден:
      виртуальное окружение не активировано или зависимости
      не установлены — pip install -r requirements.txt

  * Начать с чистой базой:
      удалить файл backend/db.sqlite3,
      затем снова: migrate + create_admin

  * Забыли пароль главного админа:
      восстановить его нельзя (суперпользователь один).
      Пересоздайте базу (см. выше) или создайте обычного
      пользователя и выдайте права: setadmin <ник> on

  * Node старой версии, Vite не стартует:
      нужен Node 20.19+ или 22.12+ (node -v)

------------------------------------------------------------
ПОДСКАЗКИ
------------------------------------------------------------
  * Выход из виртуального окружения:  deactivate
  * Регистрация игроков — на сайте, кнопка «Регистрация».
  * Тема оформления меняется в профиле (нужен аккаунт).
  * Победа — 3 очка, ничья — 1, поражение — 0.
